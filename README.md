# ColorOS Style Calculator

A clean and modern calculator UI inspired by ColorOS 16, built with plain HTML, CSS, and JavaScript.

## Features

- Modern mobile-inspired layout
- Soft rounded buttons with smooth interaction effects
- Keyboard support (numbers, operators, Enter, Backspace, Escape)
- Basic operations: addition, subtraction, multiplication, division, percent
- Responsive design for desktop and mobile

## Project Structure

- `index.html` - Calculator layout
- `style.css` - UI styles and animations
- `index.js` - Calculator logic and keyboard handling

## How To Run

1. Open the project folder.
2. Open `index.html` in any browser.

No build step or dependencies are required.

## Controls

- `AC` - Reset calculator
- `⌫` - Backspace
- `=` or `Enter` - Calculate result
- `Escape` - Clear all

## Notes

This is a front-end-only calculator intended for learning and UI practice.
